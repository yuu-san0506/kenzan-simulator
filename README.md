# シーシャ剣山プランナー

シーシャのホイル穴あけ用剣山（306穴）のパターンを考えるためのプランナーです。
GitHub Pages でそのまま使えます（`index.html` を開くだけ）。

## 使い方

- 盤面の穴をタップするたびに **大穴（赤い丸）→ 小穴（緑の丸）→ 無印** と切り替わります
- **まち針モード**では、タップした場所に小さな青い穴が等間隔に並びます（個数と範囲はスライダーで調整）
- 背景は **白黒市松／銀色市松／銀色一色（穴なし）** の3種から切り替えできます
- パターンに名前を付けて保存できます。印とパターンはお使いのブラウザに保存されるので、他の人のデータと混ざることはありません

## 補足

- 盤面の306穴はけむみ様製作のBULL（段ごとの本数 96／96／60／36＋中心18）をもとに再現しています
